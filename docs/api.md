# Internal implementation contract

Local single-user Forma CMS. Vue 3 Vite Studio, Express TypeScript server. Never read or disclose .credentials. Runtime data .data ignored. Shared types in shared/types.ts. UI Russian.

API JSON success direct response, errors {error:string}. All mutations require X-Forma-Request: studio; enforce same-origin. GET /api/bootstrap => Bootstrap. PUT /api/files body {revision,files: Partial<SiteFiles>} => {project,validation}; PUT /api/content {revision,content:SiteContent} => same. POST /api/chat {message,attachmentIds:string[],sectionId?:string} => {runId}; polling GET /api/bootstrap. POST /api/runs/:id/cancel => {ok:true}. POST /api/attachments raw bytes with headers X-File-Name: encodeURIComponent(name), Content-Type actual => Attachment. DELETE /api/attachments/:id. POST /api/publish {revision,label?} => {project,release}; POST /api/releases/:id/restore {revision} => {project,validation} restores draft only. POST /api/integrations {revision,integration:Integration,secret?:string} => {project}; DELETE /api/integrations/:id {revision} => {project}. GET /api/export?framework=nuxt|next returns downloadable application/zip with generated project files and referenced media. GET /api/auth/status => AuthStatus; POST /api/auth/connect {provider:'chatgpt'} => {url}; POST /api/auth/connect {provider:'api-key',apiKey,model?} => AuthStatus; POST /api/auth/disconnect. GET /api/auth/callback internal OAuth loopback. Preview served separate origin http://127.0.0.1:4311/preview?revision=N; published /published on that origin. Forms POST /forms/:formId on preview origin: preview submissions refused, only published token accepted. Parent postMessage {type:'forma:select',sectionId} from preview. Studio http://127.0.0.1:4310. Preview message origin check.

SiteFiles source of truth: content.json parsed SiteContent, styles.css CSS overrides, script.js browser JS; only these three source files are permitted. Custom HTML sections supported (HTML literal) with JS in script.js. Feature requests use model tools to update these real source files and integrations. Agent always modifies isolated in-memory copy then validate+commit to draft with base revision check; no shell execution. Provider must honestly error when not connected. Templates via explicit /api/templates/form action are labelled deterministic. Publishing preview snapshot atomic; never auto publish.
